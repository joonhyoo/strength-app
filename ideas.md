# Main Idea

An app where I can program exercises for athletes, and athletes can view their workouts

## Problem being solved

Easier to deliver workouts since athletes can just open the app
Smoother interface than opening a PDF or readme file

## Tech to solve problems

SvelteKit - Fullstack JS Framework to build the app
Tailwind - CSS framework to accelerate styling
Daisy UI - Tailwind library to simplify UI implementation
SupaBase - PostGreSQL database

## MVP Features

Athlete can view workout for today
Athlete can view workouts for other days
Athlete can View individual exercises
Athlete can mark weights/reps to exercises (reps should be optional as it should be pre-programmed)
Exercises show completion status on workout
Workout tracks Not started, In progress, complete
History to view previous session sets and weights
Coach can view list of athletes
Coach can view calender for each athlete containing all programmed exercises in a compact view
Coach can add exercises to any day of the week
Coach can remove exercises to any day of the week

## Future Features

Create templates (set of pre-determined workouts including reps and sets)
Assign templates to athletes
Opt out of exercises
Choose replacement exercises

Track progression (unsure how this will work, so just an idea)
