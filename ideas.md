# Main Idea

An app where I can program exercises for athletes, and athletes can view their workouts

---

| **Technology** | Use case                   |
| :------------- | :------------------------- |
| SvelteKit      | Fullstack JS Framework     |
| Tailwind       | CSS Framework              |
| Daisy UI       | Tailwind library           |
| SupaBase       | Auth + PostGreSQL Database |

---

## MVP Features

---

### Athlete Features

**Workout Views**

- [x] Athlete can view workout for today
- [x] Athlete can view workouts for other days
- [x] Athlete can View individual exercises

**Exercise Tracking**

- [x] Athlete can mark weights for exercises
- [x] Athlete can mark reps for exercises (optional as pre-programmed)
- [x] Exercises show completion status on workout

**Workout Status**

- [ ] Not Started
- [ ] In Progress
- [ ] Complete

**History**

- [ ] History to view previous session sets and weights

---

### Coach Features

**Athlete Management**

- [x] Coach can view list of athletes

**Programming Calendar**

- [x] Coach can view calender for each athlete (compact view)
- [x] Coach can add exercises to any day of the week
- [x] Coach can remove exercises to any day of the week
